# 医美消费心理学：理性决策指南

一本深入剖析医美消费背后心理机制的科普读物，帮助消费者做出理性决策。

## 🌟 项目特色

- **📚 30万字深度内容**：6个部分，15个章节的全面分析
- **🎨 图文并茂**：丰富的SVG插图、Mermaid图表、数据可视化
- **🔬 科学严谨**：基于心理学、神经科学、行为经济学的研究
- **🛠️ 实用工具**：自测量表、决策清单、评估工具
- **📱 现代设计**：响应式设计，支持深色模式

## 🚀 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 本地运行

```bash
mkdocs serve
```

访问 `http://localhost:8000` 查看网站

### 构建部署

```bash
mkdocs build
```

生成的静态文件在 `site/` 目录中
